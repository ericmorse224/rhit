Rose-Hulman Institute of Technology (RHIT) github contains all of the work, except ECE230 and ECE434 class, in individual branches within RHIT main branch.
I moved all branches into individual folders for better organization.

ECE230 folder is Embedded C code from Introduction to Embedded Systems class.

ECE310 folder is Matlab code from Communication Systems class.

ECE320 folder is Simulink and C code from Linear Controls class (some code was provided by professor to modify).

ECE333 folder is Verilog code from Embedded Systems class

ECE341 folder is Matlab code from Electromagnetic Fields class.

ECE380 folder is LabVIEW code from Discrete Time and Continuous Signals class.

MATLAB folder is Matlab code that I created while at Rose-Hulman.

PCB folder is PCB layout that I created at Rose-Hulman.

PspiceFiles folder is Orcad Pspice files that I created at Rose-Hulman.
